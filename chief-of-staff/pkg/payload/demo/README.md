# Demo data (synthetic)

Everything in this folder is invented for demonstration and testing.
Kestrel Ridge Minerals, Priya Raman and Tom Whitlock do not exist. Addresses use
example.com. No real customer, deal, email or meeting is included.

The fixtures stand in for connector results:

| File | Stands in for |
|---|---|
| fixtures/calendar_event.json | A calendar event read |
| fixtures/calendar_busy.json | Busy blocks for the following week |
| fixtures/crm_deal.json | A CRM deal and its contacts |
| fixtures/email_thread.json | The latest email thread |
| fixtures/transcript.md | A meeting transcript |

Use them with demo data only: `bin/cos --demo ...`. See docs/FIRST_RUN.md.
